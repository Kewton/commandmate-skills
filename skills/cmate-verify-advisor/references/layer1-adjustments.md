# 層 1 の調整式（正本）

層 1 は `scripts/verify-advisor.mjs` が履歴の数値だけから計算する部分である。
**同一入力 → 同一出力**（fixture テストで固定）。層 1 が出せる変更は `set-timeout` /
`set-option` / `reorder-gates` の 3 種だけで、**ゲート削除という操作は存在しない**。
方向の分類と適用の可否は [`change-classification.md`](change-classification.md) が正本。

どの調整も、実行回数が `--min-samples`（既定 5）に達していないゲートには助言しない。

## 1. `timeoutSec` — p99 × 1.5 と、その下限

設計上の式は「実測所要時間の p99 × 1.5」である。ただし 2 つの下限を足してある。

1. **実測最大値**を下回らない。nearest-rank の p99 はサンプル数が 100 を超えると最大値より
   下に来る。実際に観測された所要時間より短い timeout は、**失敗を製造する**。製造された
   失敗はすり抜け率を下げず、「このゲートは信用できない」という学習を生んで最終的に
   ゲートが外される
2. **30 秒**を下回らない。履歴は普通、暖まった開発機で記録される。キャッシュの無い CI runner は
   数倍遅い。ローカルの速い実測をそのまま持ち込むと、他所でだけ落ちるゲートになる

上限は `cmate-verify` のランナーが受理する 7200 秒である。範囲外の値は助言ではなく壊れた
設定になるので、提案の時点で丸める。加えて 2 つの黙り込み条件がある。

- 現在値との差が **`max(5 秒, 現在値の 20%)` 未満**なら提案しない。雑音を diff に流さない
- **現在の timeout に達した run がある**とき（exit 124、または所要が timeout の 95% 以上）は
  短縮を提案しない。その分布は timeout 自身に切り詰められており、それを根拠に同じ timeout を
  さらに縮めることになるためである

### `--apply` する前に人間が読むもの

**timeout の短縮は「強める」側なので `--apply` の対象である。** 履歴が速いマシンだけの
ものである場合、短縮案は実態より攻めた値になりうる。`--apply` する前に diff の
`p99 ... (slowest ...)` を読み、**最も遅い実行環境で通るか**を判断すること。判断したくない
場合は `--apply` を付けなければよい（既定は提案だけである）。

## 2. ゲート順 — fail-fast の全順序

`(失敗率 降順, 実行時間の中央値 昇順, 宣言順)` の全順序で並べ替える。ゲートは 1 つ失敗しても
残りが実行されるので、順序は打ち切りではなく**失敗が読めるまでの時間**の問題である。
**並べ替えはゲートの集合を変えない**（変えようとすると内部ガードが停止する）。

宣言された全ゲートが `--min-samples` に達していないときは並べ替えを提案しない。
知らないゲートを動かさないためである。

## 3. `maxLogTailBytes` — 切れているときだけ増やす

**失敗した** run の保存済みログ末尾が予算ぴったりに達し、かつ失敗サマリ行の「形」に一致する
行を含まない（＝原因が末尾の前で切れている）ときだけ、増額を提案する。提案値は現在値の
2 倍で、既定の 8192 バイトを下限、1 MiB を上限とする。

判定には `verify show <id> --json` が要る（`verify history --json` の gate には `logTail` が
入っていない）。`--no-details` を渡した run では、ログ予算の判定は**未評価**と明示される。
黙って「問題なし」にはならない。

## 4. コメントは書き換えない

このスクリプトは verify.yaml を再生成せず、行を編集する。timeout の理由を書いたコメントは
**そのゲートに付いたまま移動する**。ただし **コメントの内容は更新しない**。
`# 1800s because ...` と書かれたゲートの timeout が 63 秒になったら、その齟齬は diff に
そのまま出る。**それは reviewer が直すものであって、ツールが書き換えるものではない**
（設定の「なぜ」を自動生成した文章で上書きするのは、レビューできる情報を減らす）。
